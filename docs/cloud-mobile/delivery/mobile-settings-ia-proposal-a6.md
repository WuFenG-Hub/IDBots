## 1. 目标架构（二级菜单）

```
「我的」一级页
├── 用户信息卡（顶部，非折叠）
│   ├── 头像 + 名字 + globalMetaId 短码
│   └── 「编辑资料」→ 二级页：个人资料（头像/名字/语言/主题）
├── 入口列表（每行 = 图标 + 标题 + 摘要/当前值 + chevron）
│   ├── 余额与流量 …… 摘要显示剩余流量/额度 → 二级页：流量与充值
│   ├── 我的 Bot …… 摘要显示「N 个 Bot」→ 二级页：Bot 管理（现列表整体迁入）
│   ├── 技能 …… 摘要显示已启用数 → 二级页：技能管理
│   ├── 通用 …… 摘要显示当前语言/主题 → 二级页：通用（语言/主题/记忆设置）
│   ├── 归档会话 → 二级页：归档会话列表（可恢复/删除）
│   ├── 项目 → 二级页：项目管理
│   └── 关于 …… 摘要显示版本号 → 二级页：关于（App 版本/契约版本）
└── 账户区（退出登录 / 注销账户，保持在一级页底部，红色弱化）
```

交互规则：
- 一级页是**入口列表**，不再平铺任何可编辑控件；每行只读展示当前值摘要。
- 二级页 = 全屏推入（右滑返回/左上角返回键），BottomSheet 仅用于确认类弹窗（登出确认、注销确认）。
- 深链：余额卡/额度卡等既有跳转路径改为打开对应二级页。
- 会话线（本批 A2–A4）不受影响：Bot 头像解析继续走 metabot:list / 会话摘要。
