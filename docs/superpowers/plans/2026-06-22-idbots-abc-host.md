# IDBots ABC Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed Agent Browser Core into IDBots as a peer-level `Bot Browser` surface that can be switched from `Bot Home`, can use local IDBots bots as ABC actors, and can route browser conversation actions back into IDBots Cowork.

**Architecture:** Keep IDBots ownership in a small renderer shell, an iframe-backed ABC browser surface, a renderer-local ABC endpoint shim, an IDBots host adapter, and one main-process Cowork session helper. ABC stays package-consumed; IDBots does not copy OAC route hosting or introduce a separate Electron `BrowserView` in Phase 1.

**Tech Stack:** Electron main/preload IPC, React 18, Vite, TypeScript, Node `node:test`, existing IDBots Cowork/MetaBot/MetaApp services, `@openagentinternet/agent-browser-*` packages version `0.3.2`.

**Source Spec:** `docs/superpowers/specs/2026-06-22-idbots-abc-host-design.md`

**Repository Note:** This repo ignores `docs/*` and `tests/*`. Any task that adds or changes plan/test files must stage them with `git add -f`, otherwise the commit can omit the work.

**Commit Rule:** Each completed task gets its own commit. After each commit, post a MetaWeb development journal with the Codex `metabot-post-buzz` skill or the local CLI wrapper, using the actual `git log -1 --format='%h %s'` output in the buzz content.

```js
export function normalizeBrowserGlobalMetaId(value) {
  return typeof value === 'string' ? value.trim() : '';
}

export function buildBotPageBrowserUri(globalMetaId) {
  const normalized = normalizeBrowserGlobalMetaId(globalMetaId);
  return normalized ? `metaid://${encodeURIComponent(normalized)}` : '';
}

export function buildMetaAppBrowserUri(sourcePinId) {
  const normalized = typeof sourcePinId === 'string' ? sourcePinId.trim() : '';
  return normalized ? `metaapp://${encodeURIComponent(normalized)}` : '';
}

export function buildLocalMetabotActorId(metabotId) {
  const parsed = Number.parseInt(String(metabotId), 10);
  return Number.isFinite(parsed) && parsed > 0 ? `idbots-metabot-${parsed}` : '';
}

export function parseLocalMetabotActorId(actorId) {
  const text = typeof actorId === 'string' ? actorId.trim() : '';
  const match = /^idbots-metabot-(\d+)$/.exec(text);
  if (!match) return null;
  const parsed = Number.parseInt(match[1], 10);
  return Number.isFinite(parsed) && parsed > 0 ? parsed : null;
}

export function sortMetabotsForBrowser(metabots) {
  return [...(Array.isArray(metabots) ? metabots : [])].sort((left, right) => {
    const leftCreated = Number.isFinite(left?.created_at) ? left.created_at : 0;
    const rightCreated = Number.isFinite(right?.created_at) ? right.created_at : 0;
    if (leftCreated !== rightCreated) return leftCreated - rightCreated;
    const leftId = Number.isFinite(left?.id) ? left.id : 0;
    const rightId = Number.isFinite(right?.id) ? right.id : 0;
    return leftId - rightId;
  });
}

export function selectDefaultBrowserMetabot(metabots) {
  return sortMetabotsForBrowser(metabots).find((metabot) => {
    return normalizeBrowserGlobalMetaId(metabot?.globalmetaid) !== '';
  }) || null;
}
```

- [ ] **Step 3: Create actor mapping helpers**

Create `src/renderer/features/botBrowser/idbotsBrowserActorModel.js`:

```js
import {
  buildLocalMetabotActorId,
  normalizeBrowserGlobalMetaId,
  selectDefaultBrowserMetabot,
  sortMetabotsForBrowser,
} from './botBrowserIntent.js';

export function metabotToBrowserActor(metabot, defaultMetabotId = null) {
  const id = Number.isFinite(metabot?.id) ? metabot.id : 0;
  const actorId = buildLocalMetabotActorId(id);
  const globalMetaId = normalizeBrowserGlobalMetaId(metabot?.globalmetaid);
  if (!actorId || !globalMetaId) return null;

  const label = typeof metabot?.name === 'string' && metabot.name.trim()
    ? metabot.name.trim()
    : `MetaBot ${id}`;
  const avatar = typeof metabot?.avatar === 'string' && metabot.avatar.trim()
    ? metabot.avatar.trim()
    : undefined;

  return {
    id: actorId,
    label,
    kind: 'idbots-agent',
    globalMetaId,
    ...(avatar ? { avatar } : {}),
    isDefault: id === defaultMetabotId,
    capabilities: ['private-chat', 'message-view', 'profile-management', 'chat-configuration'],
    localMetabotId: id,
  };
}

export function metabotsToBrowserActors(metabots) {
  const defaultMetabot = selectDefaultBrowserMetabot(metabots);
  const defaultMetabotId = defaultMetabot?.id ?? null;
  return sortMetabotsForBrowser(metabots)
    .map((metabot) => metabotToBrowserActor(metabot, defaultMetabotId))
    .filter(Boolean);
}

export function selectDefaultBrowserActor(metabots) {
  const defaultMetabot = selectDefaultBrowserMetabot(metabots);
  if (!defaultMetabot) return null;
  return metabotToBrowserActor(defaultMetabot, defaultMetabot.id);
}
```

```js
import { buildMetaAppBrowserUri, canOpenMetaAppInBrowser } from '../../components/metaapps/metaAppLaunch.js';

function text(value) {
  return typeof value === 'string' ? value.trim() : '';
}

export function localMetaAppToBrowserRecord(app, resolvedUrl) {
  if (!canOpenMetaAppInBrowser(app)) return null;
  const runUrl = text(resolvedUrl);
  if (!runUrl) return null;

  const sourcePinId = text(app.sourcePinId);
  const name = text(app.name) || sourcePinId;
  const ownerGlobalMetaId = text(app.creatorMetaId);

  return {
    pinId: sourcePinId,
    firstPinId: sourcePinId,
    operation: 'local-installed',
    title: name,
    appName: name,
    prompt: text(app.prompt) || undefined,
    icon: text(app.icon) || undefined,
    coverImg: text(app.cover) || undefined,
    intro: text(app.description) || undefined,
    version: text(app.version) || '0.0.0',
    runtime: 'idbots-local',
    indexFile: text(app.entry) || 'index.html',
    code: text(app.codePinId),
    content: text(app.codePinId),
    contentType: 'text/html',
    codeType: 'html',
    tags: [],
    ownerGlobalMetaId,
    network: 'mvc',
    localUiUrl: runUrl,
    runUrl,
    updatedAt: Number.isFinite(app.updatedAt) ? app.updatedAt : Date.now(),
    source: text(app.sourceType) || 'idbots-local',
    raw: {
      app,
      browserUri: buildMetaAppBrowserUri(app),
    },
  };
}
```

```ts
      .map((action) => {
        if (action.kind !== 'private-chat') return action;
        const payload = payloadRecord(action.payload);
        const peerGlobalMetaId = text(payload.targetGlobalMetaId) || text(payload.to);
        return {
          ...action,
          kind: 'open-conversation',
          payload: {
            ...payload,
            peerGlobalMetaId,
          },
        };
      }),
  };
}

export interface CreateIdbotsBrowserHostAdapterInput {
  listMetabots: () => Promise<Metabot[]>;
  listMetaApps: () => Promise<MetaAppRecord[]>;
  resolveMetaAppUrl: (app: MetaAppRecord) => Promise<string>;
  openConversation: (request: BotBrowserConversationRequest) => Promise<void>;
  fetch?: typeof fetch;
}

export function createIdbotsBrowserHostAdapter(input: CreateIdbotsBrowserHostAdapterInput): BrowserHostAdapter {
  let browserConfig: BrowserConfigContainer = {
    browser: {
      ...createDefaultBrowserConfig(),
      localMode: true,
    },
  };
  const fetchImpl = input.fetch ?? globalThis.fetch.bind(globalThis);

  async function localMetabots(): Promise<Metabot[]> {
    return input.listMetabots();
  }

  async function getRuntime(_runtimeInput: BrowserRuntimeInput = {}): Promise<BrowserCommandResult<BrowserRuntimeSnapshot>> {
    const metabots = await localMetabots();
    const actors = metabotsToBrowserActors(metabots);
    return browserSuccess({
      host: {
        kind: 'idbots',
        name: 'IDBots',
        localMode: true,
      },
      actors,
      defaultActor: selectDefaultBrowserActor(metabots),
      defaultUri: null,
      features: {
        privateChat: true,
        serviceCall: false,
        cacheManagement: false,
        templateSettings: true,
        walletLogin: false,
      },
      labels: {
        actorChip: 'Using',
        noActorTitle: 'No local Bot',
        noActorBody: 'Create a local Bot before opening Bot Browser.',
        noActorAction: {
          label: 'Create Bot',
        },
      },
    });
  }

  async function resolveResource(resolveInput: BrowserResolveInput): Promise<BrowserCommandResult<BrowserResolveResult>> {
    const config = resolveBrowserConfig(browserConfig);
    const resolved = await resolveBrowserResource({
      uri: resolveInput.uri,
      config,
      fetch: fetchImpl,
      metaAppLookup: async (pinId) => {
        const apps = await input.listMetaApps();
        const app = apps.find((candidate) => text(candidate.sourcePinId) === pinId) ?? null;
        if (!app) return null;
        const runUrl = await input.resolveMetaAppUrl(app);
        return localMetaAppToBrowserRecord(app, runUrl);
      },
    });
    return resolved.ok ? browserSuccess(normalizeBrowserActions(resolved.data)) : resolved;
  }

  async function getSettings(_settingsInput: BrowserSettingsInput = {}): Promise<BrowserCommandResult<BrowserSettingsSnapshot>> {
    return browserSuccess(toSettingsSnapshot(browserConfig));
  }

  async function updateSettings(settingsInput: BrowserSettingsUpdateInput): Promise<BrowserCommandResult<BrowserSettingsSnapshot>> {
    try {
      browserConfig = applyBrowserSettingsUpdate(browserConfig, settingsInput.browser);
      return browserSuccess(toSettingsSnapshot(browserConfig));
    } catch (error) {
      return browserFailure('invalid_browser_settings', error instanceof Error ? error.message : String(error));
    }
  }

  async function getCache(_cacheInput: BrowserCacheInput = {}): Promise<BrowserCommandResult<BrowserCacheSnapshot>> {
    return browserSuccess({});
  }

  async function clearCache(_cacheInput: BrowserCacheClearInput): Promise<BrowserCommandResult<BrowserCacheClearResult>> {
    return browserSuccess({});
  }

  async function runTrustedAction(actionInput: BrowserTrustedActionInput): Promise<BrowserCommandResult<BrowserTrustedActionResult>> {
    if (actionInput.kind === 'copy-uri') {
      return browserSuccess({
        kind: 'copy-uri',
        handled: true,
        data: {
          copiedText: text(actionInput.payload?.uri) || text(actionInput.payload?.currentUri) || text(actionInput.resourceUri),
        },
      });
    }

    if (actionInput.kind === 'open-conversation' || actionInput.kind === 'private-chat') {
      const payload = payloadRecord(actionInput.payload);
      const peerGlobalMetaId = text(payload.peerGlobalMetaId)
        || text(payload.targetGlobalMetaId)
        || text(payload.to);
      const localMetabotId = parseLocalMetabotActorId(actionInput.actorId);
      if (!localMetabotId) {
        return browserFailure('browser_identity_required', 'Open conversation requires a selected local IDBots bot.');
      }
      if (!peerGlobalMetaId) {
        return browserFailure('invalid_browser_action', 'Open conversation requires peerGlobalMetaId.');
      }
      await input.openConversation({
        actionKind: actionInput.kind,
        actorId: actionInput.actorId ?? null,
        resourceUri: actionInput.resourceUri,
        peerGlobalMetaId,
        peerName: text(payload.peerName) || null,
        peerAvatar: text(payload.peerAvatar) || null,
      });
      return browserSuccess({
        kind: actionInput.kind,
        handled: true,
        data: {
          message: 'Conversation opened in IDBots.',
        },
      });
    }

    return browserFailure('browser_action_not_supported', `Browser action is not supported by IDBots: ${actionInput.kind}`);
  }

  return {
    getRuntime,
    resolveResource,
    getSettings,
    updateSettings,
    getCache,
    clearCache,
    runTrustedAction,
  };
}
```

```ts
import type {
  BrowserCacheClearInput,
  BrowserHostAdapter,
  BrowserTrustedActionKind,
} from '@openagentinternet/agent-browser-host-contract';

export interface BotBrowserShimRequest {
  url: string;
  method?: string;
  body?: unknown;
}

export interface BotBrowserShimResponse {
  status: number;
  body: unknown;
}

function commandBody(result: { ok: boolean; state: string; data?: unknown }): unknown {
  return result.ok ? { ok: true, state: result.state, data: result.data } : result;
}

function requestUrl(rawUrl: string): URL {
  return new URL(rawUrl, window.location.origin);
}

async function readBody<T>(body: unknown): Promise<T> {
  return (body && typeof body === 'object' ? body : {}) as T;
}

export function createBrowserEndpointShim(adapter: BrowserHostAdapter) {
  return async function handleBrowserEndpointRequest(request: BotBrowserShimRequest): Promise<BotBrowserShimResponse> {
    const url = requestUrl(request.url);
    const method = (request.method || 'GET').toUpperCase();
    const actorId = url.searchParams.get('actorId') || undefined;

    if (url.pathname === '/api/browser/runtime' && method === 'GET') {
      return { status: 200, body: commandBody(await adapter.getRuntime({ actorId })) };
    }

    if (url.pathname === '/api/browser/resolve' && method === 'GET') {
      return {
        status: 200,
        body: commandBody(await adapter.resolveResource({
          actorId,
          uri: url.searchParams.get('uri') || '',
        })),
      };
    }

    if (url.pathname === '/api/browser/settings' && method === 'GET') {
      return { status: 200, body: commandBody(await adapter.getSettings({ actorId })) };
    }

    if (url.pathname === '/api/browser/settings' && method === 'PATCH') {
      return {
        status: 200,
        body: commandBody(await adapter.updateSettings({
          actorId,
          browser: await readBody<Record<string, unknown>>(request.body),
        })),
      };
    }

    if (url.pathname === '/api/browser/cache' && method === 'GET') {
      return { status: 200, body: commandBody(await adapter.getCache({ actorId })) };
    }

    if (url.pathname === '/api/browser/cache' && method === 'DELETE') {
      const body = await readBody<BrowserCacheClearInput>(request.body);
      return { status: 200, body: commandBody(await adapter.clearCache({ ...body, actorId })) };
    }

    if (url.pathname === '/api/browser/actions' && method === 'POST') {
      const body = await readBody<{
        resourceUri?: string;
        kind?: BrowserTrustedActionKind;
        payload?: Record<string, unknown>;
      }>(request.body);
      return {
        status: 200,
        body: commandBody(await adapter.runTrustedAction({
          actorId,
          resourceUri: body.resourceUri || '',
          kind: body.kind || 'copy-uri',
          payload: body.payload,
        })),
      };
    }

    return {
      status: 404,
      body: {
        ok: false,
        state: 'failed',
        code: 'browser_endpoint_not_found',
        message: `Unsupported Browser endpoint: ${method} ${url.pathname}`,
      },
    };
  };
}
```

```ts
const BRIDGE_CHANNEL = 'idbots-bot-browser-v1';
const INITIALIZATION_MARKER = 'if (document.readyState === \\'loading\\') {';

export function isBotBrowserBridgeMessage(value: unknown): value is {
  channel: typeof BRIDGE_CHANNEL;
  id?: string;
  type: string;
  request?: {
    url: string;
    method?: string;
    body?: unknown;
  };
  response?: unknown;
} {
  return Boolean(
    value &&
    typeof value === 'object' &&
    (value as { channel?: unknown }).channel === BRIDGE_CHANNEL,
  );
}

function bridgeScript(): string {
  return `
window.__IDBOTS_BOT_BROWSER_CHANNEL__ = '${BRIDGE_CHANNEL}';
window.__idbotsBrowserRequestSeq = 0;
window.__idbotsBrowserPending = new Map();
window.addEventListener('message', function(event) {
  var data = event.data || {};
  if (data.channel !== window.__IDBOTS_BOT_BROWSER_CHANNEL__) return;
  if (data.type === 'endpoint-response') {
    var pending = window.__idbotsBrowserPending.get(data.id);
    if (!pending) return;
    window.__idbotsBrowserPending.delete(data.id);
    if (data.error) {
      pending.reject(new Error(data.error));
      return;
    }
    pending.resolve(data.response);
    return;
  }
  if (data.type === 'open-uri') {
    Promise.resolve()
      .then(function() {
        if (data.actorId && typeof window.selectUsingIdentity === 'function') {
          return window.selectUsingIdentity(data.actorId);
        }
      })
      .then(function() {
        if (data.uri && typeof window.navigateTo === 'function') {
          return window.navigateTo(data.uri);
        }
      })
      .catch(function(error) {
        if (typeof window.showToast === 'function') {
          window.showToast(error && error.message ? error.message : 'Open failed.');
        }
      });
  }
  if (data.type === 'refresh-runtime' && typeof window.loadRuntime === 'function') {
    window.loadRuntime().catch(function(error) {
      if (typeof window.showToast === 'function') {
        window.showToast(error && error.message ? error.message : 'Runtime refresh failed.');
      }
    });
  }
});
window.fetch = function(input, init) {
  var url = typeof input === 'string' ? input : input && input.url;
  if (!url || String(url).indexOf('/api/browser/') !== 0) {
    return window.__idbotsOriginalFetch(input, init);
  }
  var id = 'req-' + (++window.__idbotsBrowserRequestSeq);
  var method = init && init.method ? init.method : 'GET';
  var body = init && typeof init.body === 'string'
    ? JSON.parse(init.body || '{}')
    : {};
  var promise = new Promise(function(resolve, reject) {
    window.__idbotsBrowserPending.set(id, { resolve: resolve, reject: reject });
  });
  window.parent.postMessage({
    channel: window.__IDBOTS_BOT_BROWSER_CHANNEL__,
    id: id,
    type: 'endpoint-request',
    request: { url: String(url), method: method, body: body }
  }, '*');
  return promise.then(function(response) {
    return new Response(JSON.stringify(response.body), {
      status: response.status || 200,
      headers: { 'content-type': 'application/json' }
    });
  });
};
window.parent.postMessage({
  channel: window.__IDBOTS_BOT_BROWSER_CHANNEL__,
  type: 'browser-ready'
}, '*');
`;

}
```

```tsx
  onOpenConversation: (request: BotBrowserConversationRequest) => Promise<void>;

}

async function listLocalMetabots(): Promise<Metabot[]> {

}

async function listLocalMetaApps(): Promise<MetaAppRecord[]> {

}

async function resolveLocalMetaAppUrl(app: MetaAppRecord): Promise<string> {
  const result = await window.electron.metaapps.resolveUrl({ appId: app.id, targetPath: app.entry });
  if (!result.success || !result.url) {
    throw new Error(result.error || 'MetaApp URL could not be resolved.');
  }
  return result.url;
}

const BotBrowserSurface = forwardRef<BotBrowserSurfaceHandle, BotBrowserSurfaceProps>(({
  visible,
  onOpenConversation,
  onError,
  onReady,
}, ref) => {
  const iframeRef = useRef<HTMLIFrameElement | null>(null);
  const iframeReadyRef = useRef(false);
  const pendingOpenUriRef = useRef<BotBrowserOpenUriInput | null>(null);
  const [srcDoc, setSrcDoc] = useState('');

  const endpointShim = useMemo(() => createBrowserEndpointShim(createIdbotsBrowserHostAdapter({
    listMetabots: listLocalMetabots,
    listMetaApps: listLocalMetaApps,
    resolveMetaAppUrl: resolveLocalMetaAppUrl,
    openConversation: onOpenConversation,
  })), [onOpenConversation]);

  useEffect(() => {
    let cancelled = false;
    buildBotBrowserSrcDoc(i18nService.getLanguage()).then((html) => {
      if (!cancelled) setSrcDoc(html);
    }).catch((error) => {
      onError(error instanceof Error ? error.message : 'Bot Browser failed to initialize.');
    });
    return () => {
      cancelled = true;
    };
  }, [onError]);

  useEffect(() => {
    iframeReadyRef.current = false;
  }, [srcDoc]);

  const deliverOpenUri = useCallback((input: BotBrowserOpenUriInput) => {
    postOpenUriToBrowser(iframeRef.current, input);
  }, []);

  const queueOrDeliverOpenUri = useCallback((input: BotBrowserOpenUriInput) => {
    if (!iframeReadyRef.current || !iframeRef.current?.contentWindow) {
      pendingOpenUriRef.current = input;
      return;
    }
    deliverOpenUri(input);
  }, [deliverOpenUri]);

  const flushPendingOpenUri = useCallback(() => {
    if (!pendingOpenUriRef.current) return;
    const pending = pendingOpenUriRef.current;
    pendingOpenUriRef.current = null;
    deliverOpenUri(pending);
  }, [deliverOpenUri]);

  useEffect(() => {
    const handleMessage = async (event: MessageEvent) => {
      if (event.source !== iframeRef.current?.contentWindow) return;
      if (!isBotBrowserBridgeMessage(event.data)) return;
      if (event.data.type === 'browser-ready') {
        iframeReadyRef.current = true;
        onReady?.();
        flushPendingOpenUri();
        return;
      }
      if (event.data.type !== 'endpoint-request' || !event.data.request) return;
      try {
        const response = await endpointShim(event.data.request);
        iframeRef.current?.contentWindow?.postMessage({
          channel: event.data.channel,
          id: event.data.id,
          type: 'endpoint-response',
          response,

          channel: event.data.channel,
          id: event.data.id,
          type: 'endpoint-response',
          error: error instanceof Error ? error.message : 'Browser endpoint failed.',
        }, '*');
      }
    };
    window.addEventListener('message', handleMessage);
    return () => window.removeEventListener('message', handleMessage);
  }, [endpointShim, flushPendingOpenUri, onReady]);

  useImperativeHandle(ref, () => ({
    async openUri(input: BotBrowserOpenUriInput) {
      queueOrDeliverOpenUri(input);
    },
    async refreshRuntime() {
      postRefreshRuntimeToBrowser(iframeRef.current);
    },
  }), [queueOrDeliverOpenUri]);

  return (
    <div className={`h-full min-h-0 bg-white dark:bg-claude-darkBg ${visible ? 'block' : 'hidden'}`}>
      {srcDoc ? (
        <iframe
          ref={iframeRef}
          title="Bot Browser"
          srcDoc={srcDoc}
          className="h-full w-full border-0 bg-white dark:bg-claude-darkBg"
        />
      ) : (
        <div className="flex h-full items-center justify-center text-sm text-claude-textSecondary dark:text-claude-darkTextSecondary">
          {i18nService.t('loading')}
        </div>
      )}
    </div>
  );
});
```

```ts
import os from 'os';
import path from 'path';
import type { CoworkStore, CoworkSession } from '../coworkStore';
import type { MetabotStore } from '../metabotStore';
import { buildCanonicalPrivateConversationExternalConversationId } from './simplemsgPeerConversation';

export interface EnsureA2ASessionInput {
  metabotId: number;
  peerGlobalMetaId: string;
  peerName?: string | null;
  peerAvatar?: string | null;
}

export interface EnsureA2ASessionResult {
  success: boolean;
  session?: CoworkSession;
  reused?: boolean;
  error?: string;
}

function text(value: unknown): string {
  return typeof value === 'string' ? value.trim() : '';
}

function defaultWorkingDirectory(): string {
  return path.join(os.homedir(), 'idbots', 'project');
}

export function ensureA2ASessionForPeer(input: {
  coworkStore: CoworkStore;
  metabotStore: MetabotStore;
  request: EnsureA2ASessionInput;
}): EnsureA2ASessionResult {
  const metabotId = Number.isFinite(input.request.metabotId) ? Math.trunc(input.request.metabotId) : 0;
  const peerGlobalMetaId = text(input.request.peerGlobalMetaId);
  if (metabotId <= 0) return { success: false, error: 'metabotId is required' };
  if (!peerGlobalMetaId) return { success: false, error: 'peerGlobalMetaId is required' };

  const metabot = input.metabotStore.getMetabotById(metabotId);
  if (!metabot) return { success: false, error: 'Local MetaBot not found' };
  if (!text(metabot.globalmetaid)) return { success: false, error: 'Local MetaBot GlobalMetaID is missing' };

  const externalConversationId = buildCanonicalPrivateConversationExternalConversationId(peerGlobalMetaId);
  const existing = input.coworkStore.getConversationMapping('metaweb_private', externalConversationId, metabotId);
  if (existing) {
    const existingSession = input.coworkStore.getSession(existing.coworkSessionId);
    if (existingSession && input.coworkStore.ensureCanonicalPeerSessionShape({
      sessionId: existingSession.id,
      metabotId,
      peerGlobalMetaId,
      peerName: input.request.peerName,
      peerAvatar: input.request.peerAvatar,
    })) {
      input.coworkStore.touchConversationMapping('metaweb_private', externalConversationId, metabotId);
      return {
        success: true,
        reused: true,
        session: input.coworkStore.getSession(existingSession.id) || existingSession,
      };
    }
    input.coworkStore.deleteConversationMapping('metaweb_private', externalConversationId, metabotId);
  }

  const config = input.coworkStore.getConfig();
  const peerName = text(input.request.peerName);
  const peerAvatar = text(input.request.peerAvatar);
  const session = input.coworkStore.createSession(
    peerName || `Private-${peerGlobalMetaId.slice(0, 12)}`,
    text(config.workingDirectory) || defaultWorkingDirectory(),
    '',
    config.executionMode || 'local',
    [],
    metabotId,
    'a2a',
    peerGlobalMetaId,
    peerName || null,
    peerAvatar || null,
  );
  input.coworkStore.upsertConversationMapping({
    channel: 'metaweb_private',
    externalConversationId,
    metabotId,
    coworkSessionId: session.id,
    metadataJson: JSON.stringify({
      peerGlobalMetaId,
      peerName: peerName || null,
      peerAvatar: peerAvatar || null,
    }),
  });
  return { success: true, reused: false, session: input.coworkStore.getSession(session.id) || session };
}
```

```ts
import type { BotBrowserConversationRequest } from './types';

export interface CreateConversationNavigationAdapterInput {
  switchToHome: () => void;
  showCowork: () => void;
  showError: (message: string) => void;
}

export function createConversationNavigationAdapter(input: CreateConversationNavigationAdapterInput) {
  return async function openConversationFromBrowser(request: BotBrowserConversationRequest): Promise<void> {
    const localMetabotId = parseLocalMetabotActorId(request.actorId || '');
    if (!localMetabotId) {
      input.showError('Select a local Bot before opening a conversation.');
      return;
    }
    const peerGlobalMetaId = request.peerGlobalMetaId.trim();
    if (!peerGlobalMetaId) {
      input.showError('Remote Bot GlobalMetaID is missing.');
      return;
    }

    const result = await window.electron.cowork.ensureA2ASession({
      metabotId: localMetabotId,
      peerGlobalMetaId,
      peerName: request.peerName || null,
      peerAvatar: request.peerAvatar || null,
    });

    if (!result.success || !result.session) {
      input.showError(result.error || 'Failed to open conversation.');
      return;
    }

    input.switchToHome();
    input.showCowork();
    await coworkService.loadSession(result.session.id);
  };
}
```

## Implementation Notes

- Keep Browser first-entry default URI as `null`; do not set `defaultUri` to the first bot page.
- The no-bot guard belongs in IDBots shell before mounting ABC. In this plan, "no-bot guard" means: if the local bot list is empty, clicking `Bot Browser` shows "No local Bot. Please create a Bot first." and does not mount ABC.
- Do not restore Browser page or acting bot across full app restart.
- Do not use timer delays as the correctness mechanism for first-entry deep links. Use the `browser-ready` bridge message and pending open-URI queue.
- Do not start a Cowork runner when opening a conversation from Browser. Create or reuse an idle A2A session and load it.
- Do not keep `private-chat` as a direct-send action in IDBots Phase 1. Normalize it to the same open conversation path.
- Do not advertise `serviceCall: true` until IDBots has a real Browser-to-order adapter.
- Do not copy OAC `/browser` route hosting or daemon page-serving code.
- Keep the ABC iframe mounted once initialized; hide it with CSS while `Bot Home` is visible.
