# Claude Agent SDK 0.2.12 → 0.3.221: Feature Delta and IDBots Opportunities

Date: 2026-08-05
Status: Reference for roadmap planning
Companion to `2026-08-05-cowork-kernel-openclaw-evaluation.md` and `2026-08-05-sdk-upgrade-0.3-risk-assessment.md`
Source: official changelog of `@anthropic-ai/claude-agent-sdk` (anthropics/claude-agent-sdk-typescript), covering 0.2.12 → 0.3.222.

## 1. Architectural / breaking changes (already handled by the upgrade)

| Version | Change |
|---|---|
| 0.2.113 | CLI distribution changed from bundled `cli.js` to per-platform native binaries; `options.env` replaces the subprocess env instead of overlaying it; `title` option; alpha `sessionStore` |
| 0.3.142 | **Breaking:** removed the v2 session API (`unstable_v2_createSession` / `unstable_v2_resumeSession` / `unstable_v2_prompt`); MCP servers connect in the background by default (`status: "pending"` in init); **Task tools (`TaskCreate`/`TaskUpdate`/`TaskGet`/`TaskList`) replace `TodoWrite` in headless/SDK sessions** |
| 0.3.143 | `@anthropic-ai/sdk` and `@modelcontextprotocol/sdk` became peer dependencies |
| 0.2.73 | Documented that `~/.claude/settings.json` env blocks override `options.env` when user settings sources are loaded — the root cause of our first-run blocker, fixed in IDBots via `settingSources: []` |

## 2. Major new capabilities by category

### 2.1 Session management API family (all new; IDBots uses none of it yet)
- `listSessions()` (0.2.53), `getSessionMessages()` (0.2.59, pagination, parallel tool results fixed 0.2.80)
- `getSessionInfo()` / `tagSession()` (0.2.75), `renameSession()` (0.2.74), `deleteSession()` (0.2.113)
- `forkSession()` (0.2.76) — branch a conversation from a point
- `listSubagents()` / `getSubagentMessages()` (0.2.89) — read subagent transcripts
- `importSessionToStore()` + `SessionStore` mirroring (0.2.113) — mirror transcripts to external storage
- Custom `sessionId` UUIDs (0.2.33)

### 2.2 Mid-session runtime control
- `getContextUsage()` (0.2.86) — context-window usage broken down by category
- `interrupt()` with typed receipts (`interrupt_receipt_v1`), `cancel_queued` (0.3.205 / 0.3.219); aborted partial messages carry `aborted: true` (0.3.214)
- `rewind_conversation` control request + `rewindFiles` (0.3.186 / 0.3.216) — rewind a conversation to an earlier point
- `mcp_set_servers` / `mcp_reconnect` / `mcp_toggle` (0.2.21+) — add/remove/reconnect MCP servers in a running session
- `set_model`, `set_permission_mode`, `set_max_thinking_tokens`, `applyFlagSettings` live agent switching (0.3.161)
- `promptSuggestion()` (0.2.47) — context-aware follow-up prompt suggestions
- `usage_EXPERIMENTAL()` (0.3.169) — session cost, plan rate limits, usage behaviors
- `reloadPlugins()` (0.2.85) / `reload_skills` / `commands_changed` events

### 2.3 Background tasks, subagents, workflows
- Task tools replace `TodoWrite` (0.3.142); `CLAUDE_CODE_ENABLE_TASKS` opt-in era (0.2.19-20)
- Background agents: `task_started` (0.2.45), `task_progress` with cumulative usage (0.2.51), `task_notification`, `background_tasks_changed` level events (0.3.203)
- `agentProgressSummaries` (0.2.72) — periodic AI-generated progress summaries for running subagents
- Workflow tool (parallel multi-agent orchestration) with progress events
- `forwardSubagentText` (0.2.119) — stream subagent text deltas to the host
- Subagent depth cap (default 1) and concurrency cap (default 20) knobs (0.3.217); `parent_agent_id` for agent trees (0.3.202)

### 2.4 Performance
- `startup()` pre-warm (0.2.89) — first query ~20x faster when startup cost is paid upfront
- MCP connections non-blocking by default (0.3.142) — session starts immediately, slow servers report `pending`
- Gateway cold-start era fixes: memory-leak fixes for long sessions (0.2.51), stderr-tail capture on exit errors (0.3.211)

### 2.5 Models, budget, structured output
- `fallbackModel` option; `system/model_fallback` events for overloaded/server_error/last_resort triggers (0.3.174)
- `effort` levels (`low|medium|high|max`) + model capability discovery (`supportsEffort`, `supportsAdaptiveThinking`) (0.2.49)
- `taskBudget` (0.2.84) — API-side token-budget pacing; `maxBudgetUsd`
- `jsonSchema` structured outputs (validated JSON results)
- `betas` option (e.g. 1M context on Sonnet)
- `terminal_reason` (0.2.91) and `stop_reason` (0.2.31) on result messages

### 2.6 Hooks expansion
New hook events since 0.2.12: `PostToolBatch`, `UserPromptExpansion`, `StopFailure`, `PostCompact`, `PermissionDenied`, `TeammateIdle`, `TaskCreated`, `TaskCompleted`, `Elicitation`, `ElicitationResult`, `ConfigChange`, `WorktreeCreate/Remove`, `InstructionsLoaded`, `CwdChanged`, `FileChanged`, `DirectoryAdded`, `MessageDisplay` (transform/hide displayed assistant text, 0.3.152). SessionStart hooks can set the session title (0.3.152).

### 2.7 UX/observability primitives
- `api_retry` system events (0.2.77; 529 → `error:'overloaded'` split 0.3.150), `status:'requesting'` (0.2.108)
- `tool_use_meta` display-friendly tool names (0.3.179) and MCP `icon_url` (0.3.181)
- `tool_result_meta` classification of denied/interrupted/cancelled tool calls (0.3.216)
- `USAGE_LIMIT_ERROR_PREFIXES` and sibling classifiers (0.3.211)
- `command_lifecycle` frames (queued/started/completed/cancelled/discarded) (0.3.206)
- Refusal detection via `stop_reason:'refusal'` (0.3.162)
- CJK/multibyte stream corruption fix (0.2.94)

### 2.8 Elicitation and sandbox
- MCP elicitation: `onElicitation` callback + `SDKElicitationCompleteMessage` (0.2.76) — MCP servers can ask the user questions interactively
- CLI-native `sandbox` option with `network.strictAllowlist` and credential masking/denial (0.2.91, 0.3.187, 0.3.199, 0.3.219)

## 3. Recommended IDBots follow-ups (ranked)

> **Status (2026-08-05): ALL 10 items are implemented on `feat/sdk-0.3-feature-integration`.**
> See `2026-08-05-sdk-0.3-integration-status-and-roadmap.md` for the full status,
> commit references, and remaining (non-original) opportunities.

1. **`startup()` pre-warm** — ✅ done (`1da2d65`). Module + binary path pre-load at app-ready. Full `startup()`/WarmQuery is single-use + fixed options — not usable for multi-provider per-session env, so we pre-load instead.
2. **`getContextUsage()`** — ✅ done (`62d4cd5`). Local mode uses SDK real per-category usage for the context ring; sandbox keeps the estimator.
3. **Surface `api_retry` / `requesting` events in the UI** — ✅ done (`ae33772`). StreamingActivityBar shows "Retrying (attempt N/M)…" / "Requesting…".
4. **Task-tools rendering compatibility (⚠️ compatibility, not optional)** — ✅ done (`8a7fce6`). TaskCreate/TaskUpdate render as checkbox lists.
5. **Background task progress + AI summaries** — ✅ done (`babce40`). Live panel for all task types + cross-session sidebar badge + `agentProgressSummaries`. Also fixed a real bug: `background_tasks_changed` REPLACE path was dead code.
6. **`promptSuggestion()`** — ✅ done (`9354d6d`). Implemented as `options.promptSuggestions` + `prompt_suggestion` event (not a function — corrected from the original doc) + chips below the composer.
7. **`rewind_conversation` / `forkSession`** — ✅ done (`5b8ebe4`). IDBots-side fork + rewind (conversation truncation). Note: `rewind_conversation` control does NOT exist in 0.3.221 — only `rewindFiles`; we implemented conversation rewind as truncation instead.
8. **`usage()` cost display** — ✅ done (`4214e69`). **DeepSeek-first**: proxy passes real usage through (fixed streaming usage loss), runner accumulates, UsageStatsChip shows tokens + est. cost at DeepSeek V4 rates. The SDK's `usage_EXPERIMENTAL` is Anthropic-priced and unusable for proxy providers — we capture from the proxy-translated result events instead.
9. **`fallbackModel`** — ✅ done (`ab92472`). Model-refusal fallback (same-provider validation); `model_refusal_fallback` event → system message.
10. **Subagent transcript viewer** — ✅ done (`1093aa1` + `fcdba93`). Live subagent panel (task events) + post-hoc transcript viewer (`listSubagents` + `getSubagentMessages`, defensive flatten of CLI-internal JSONL).

## 4. Deliberately deferred

- **CLI-native sandbox**: IDBots has its own QEMU micro-VM sandbox with host-tool RPC; the built-in sandbox is Linux-container-oriented. Watch, don't adopt yet.
- **`SessionStore` mirroring**: IDBots already persists transcripts in SQLite (`CoworkStore`); adopting SessionStore would duplicate that.
- **Fast mode**: Anthropic-first-party only; incompatible with the multi-provider proxy architecture.

## 5. Notes

- Feature availability for items in §3 depends on the provider path: anything flowing through the OpenAI-compat translation proxy inherits the proxy's capabilities (e.g. `getContextUsage` is a local control call and works regardless; `usage()` cost fields are Anthropic-oriented).
- The Task-tools switch (0.3.142) also means `TodoWrite`-specific prompt guidance or UI strings anywhere in IDBots should be audited.
