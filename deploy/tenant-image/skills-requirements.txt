# of the imports in their scripts:
#   SKILLs/docx/ooxml/scripts/{unpack,pack}.py      -> defusedxml, lxml
#   SKILLs/pptx/scripts/*.py                        -> python-pptx, Pillow
#   SKILLs/pptx/ooxml/scripts/*.py                  -> defusedxml, lxml
#   SKILLs/pptx (text extraction)                   -> markitdown[pptx]

#   SKILLs/pdf/scripts/*.py                         -> pypdf, pdf2image, Pillow,
#                                                      pytesseract
# python-pptx must import in the venv (REQ-A-26).
#
# System (apt) counterparts live in the Dockerfile: poppler-utils for
# pdf2image/pdftotext, tesseract-ocr(-chi-sim) for pytesseract,
# libreoffice-writer/-calc/-impress for soffice, pandoc for docx conversions.
