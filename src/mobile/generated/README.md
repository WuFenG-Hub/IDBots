# Generated mobile artifacts

`ipc-contract.json` (and any other files in this directory) is generated by
WS-A's IPC contract generator (REQ-A-23) from the desktop preload and the
frozen allowlist (`docs/cloud-mobile/02-ipc-allowlist-v1.md`). It is never
edited by hand; the generator output lands here and the mobile gateway shim
(T3) builds `window.electron` from it.
